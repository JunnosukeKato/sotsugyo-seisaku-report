使い方の手引き：見た目の案（v25）

ツールの「使い方の手引き」2冊（学生用・教員用。A4 縦の PDF で配り、印刷もできる冊子）の見た目を3案作りました。全体を作る前に方向を決めていただくための見本で、各案とも同じ4ページ（学生用の表紙・学生用「3 本文を書く」・教員用の表紙・教員用「3 年度の設定をする」）を並べています。画面の画像は本物のツールを撮ったもので（学生用はログインなしで試せる開発版、管理ページは試験用のサーバー）、番号の吹き出しを重ねています。文章は仮ですが、今のツールの動きに合わせて書いています。人名・学籍番号（文化　花子・00ZZ0123）と管理ページのメールアドレスは架空です。画像を押すと大きく見られます。おすすめの案には印を付けています。

この v25 で決めていただきたいこと

  1. 見た目の方向（案A／B／C） おすすめ：案A（ツールと同じ藍と生成り。白黒で印刷しても崩れない）
  2. 学生用と教員用を同じ見た目にするか おすすめ：同じ案で、学生用だけ少しやわらかく（例：案A に、案C の手順のアイコンを足す）
  3. 配り方：PDF だけか、印刷もするか（印刷するなら白黒か） 案B は、印刷するなら向きません（下の「白黒で印刷したとき」）
  4. 目次（章立て）はこの8章ずつでよいか 表紙の目次を見てください（ページ数は仮）
どの案も同じところ
  • 文字：書体はツールと同じ BIZ UD明朝・BIZ UDPゴシック。手順の説明・注意などの本文は 9.5pt 以上（見出しは 10.5〜25pt）。9.5pt より小さいのは、柱（ページの上や下の小さな見出し）・ページ番号・表紙の添え書き（学科名・注記・「スマホで読み取る」など）・目次の補足・英字の飾り・A／B の記号だけで、8.5〜9pt です（作るときに、案ごとに文字の大きさを測って確かめています）。
  • 画面の画像の中の字は、実物の画面を縮めたものなので小さくなります。そのため、押すところには番号の吹き出しと囲みを付け、番号と同じ順に横（下）で説明しています。
  • 表紙には、ツールの URL と QR コード（スマホで読み取ると開く）。教員用は「学生に配る URL」として載せ、管理ページの URL は「管理者からのメールで知らせる」としています（公開の資料に管理ページの URL を載せないため）。
  • 作り方：node scripts/mockup-shots-v25.mjs で、画面を撮る → 案ごとの HTML → Edge で PDF（mockups/v25/a.pdf など）→ ページの画像、まで作ります。全体を作るときも同じ流れで、画面が変わったら撮り直せます。

案A「紙と墨」：ツールと同じ藍と生成りの、端正な冊子

案B「雑誌風」：大きな画面写真・色の帯・大きな番号で見せる

案C「やわらか」：角の丸い枠・アイコン・余白多めで親しみやすく

白黒で印刷したとき（学生用「本文を書く」のページ）

確かめたことPDF をそのまま白黒（グレー）にして並べました。学内のプリンターや家のプリンターで白黒で刷っても、番号の吹き出しと手順の説明が読めるかを見ています。

おすすめは案A：学生がふだん見るツールの画面と同じ藍・生成り・明朝なので、冊子のどこを見ても「あの画面の話だ」とつながります。配るのは PDF でも印刷でもよく、白黒で刷っても番号の吹き出しがいちばんはっきり残り、紙の端まで塗る部分も少ないので学内のプリンターでもそのまま刷れます。教員用は罫と余白で区切った落ち着いた紙面で、要点を拾いやすくできます。学生用の「やさしさ」が足りないと感じられたら、案C の手順のアイコンや「知っておくと安心」の角丸の囲みを、案A の学生用にだけ足すことができます。案B は画面の画像が大きく華やかですが、トナーの量と紙の端の白いふちが気になり、印刷して配るなら向きません（PDF だけで配るなら候補になります）。案C は学生には親しみやすい反面、白黒では淡い色の区切りが消え、教員用には少しやわらかすぎます。
